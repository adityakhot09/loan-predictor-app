
# Loan Predictor App

A Machine Learning-based web application that predicts whether a loan application will be approved or rejected based on applicant details.

---

## Features

- Predicts loan approval status instantly
- User-friendly web interface
- Machine Learning-based prediction system
- Stores prediction data
- Responsive frontend design

---

# Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Joblib
